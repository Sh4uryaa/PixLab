Architecture Documentation

PixLab C++17 OOP & WASM Specification

📦

1. Encapsulation

class Image wraps a flat contiguous 1D heap buffer (std::vector<RGBTRIPLE>) with coordinates mapped via row * width + col. Provides safe, bounds-checked access throwing std::out_of_range.

🧩

2. Abstraction

class Filter exposes a clean, contract-driven pure virtual method virtual void apply(Image&) = 0 and protected clamping utility clamp() enforcing [0, 255] RGB bounds.

🏛️

3. Inheritance

Derived concrete filters (GrayscaleFilter, SepiaFilter, BlurFilter, ReflectFilter, PixelateFilter, VignetteFilter, UnsharpMaskEnhancer) inherit and implement custom spatial algorithms.

⚡

4. Polymorphism

FilterFactory::create(...) instantiates concrete filters returning std::unique_ptr<Filter>, dispatched dynamically via base class pointer without caller awareness of concrete types.

Zero-ML & Memory Safety Guarantee

  • Pure Arithmetic: Spatial convolutions (3×3 box blur, Laplacian difference sharpening) run strictly using integer and floating-point arithmetic. No machine learning or neural networks.
  • In-RAM Execution: Buffers are deserialized directly from browser memory. No backend server or disk storage is involved.
  • Explicit Memory Lifecycle: JavaScript allocates WASM heap memory via _malloc, triggers execution, clones bytes into a safe typed array slice, and calls _freeBuffer to prevent leaks.
